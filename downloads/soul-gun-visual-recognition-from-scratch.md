# Visual Recognition From Scratch

> *"The Eye sees patterns where others see noise."*

Build visual recognition pipelines from first principles. No frameworks — just math and code.

## Step 1: Image Representation
Represent images as tensors. Understand color spaces, normalization, and data augmentation.

## Step 2: Feature Extraction
Implement edge detection (Sobel, Canny), corner detection (Harris), and SIFT-like feature descriptors.

## Step 3: Classification
Build a simple CNN from scratch using NumPy. Forward pass, backpropagation, convolutional kernels.
