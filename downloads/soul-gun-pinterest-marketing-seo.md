# Pinterest Marketing & SEO

Pinterest is a visual search engine, not a social network. Content lives 3-6+ months. The algorithm is powered by the **Interest Taxonomy** (Pin2Interest system) — not hashtags. This skill covers the two separate tag systems (hashtags vs. interest tags), board categories, keyword SEO, and a complete playbook for buyasoul.online.

## Mental Model

```
PINTEREST RANKING (weighted):
┌─────────────────────────────────────────────┐
│  PIN QUALITY (saves 48h + clicks)    30%    │
│  KEYWORD RELEVANCE (titles+desc)      25%    │
│  INTEREST TAXONOMY TAGS (board cat.)  20%    │
│  DOMAIN TRUST (verified site)          15%    │
│  ACCOUNT CONSISTENCY (fresh pins)      10%    │
└─────────────────────────────────────────────┘

HASHTAGS (#) → near 0% weight, supplemental only
TAGS (interest taxonomy) → 20% weight, CRITICAL
```

## Step 1: Understand the Two Tag Systems

### Hashtags (#tag) — Pin Description Only

| Fact | Detail |
|---|---|
| Where they go | End of pin description ONLY |
| Optimal count | 2-5 per pin |
| SEO weight | Near zero in 2026 |
| Purpose | Supplementary keyword signal, hashtag feed |
| Key rule | Rotate them per pin — never reuse same set |
| Avoid | Never in pin titles, board names, or bios |

### Interest Tags (Taxonomy) — The REAL Algorithm Signal

Pinterest's **Pin2Interest** AI automatically classifies every pin into a hierarchical taxonomy (up to 11 levels deep). These internal tags determine where your pin appears. You cannot set them directly — you **teach** the algorithm through:

1. **Board category** — The dropdown you select when creating a board
2. **Board name + description** — Keyword signals
3. **Pin title + description** — Keyword matching
4. **Image content** — Visual AI classification

## Step 3: The Complete Tag Strategy

### A. Interest Tags — Teach the Algorithm

The Interest Taxonomy uses paths like:
```
Technology > Artificial Intelligence > AI Software
Education > Self Improvement > Personal Development
Film Music & Books > Books > Philosophy
Quotes > Inspirational Quotes > Spiritual Quotes
```

**How to teach the algorithm the correct tags:**
1. Name boards with taxonomy-aligned keywords
2. Write board descriptions using those exact phrases
3. Assign the correct board category (Step 2)
4. Use matching keywords in pin titles and descriptions
5. Pin consistently to reinforce the signal

## Step 5: Pin Optimization

### Pin Image

| Requirement | Spec |
|---|---|
| Aspect ratio | **2:3** only (1000x1500px) |
| Text overlay | Bold, readable at 236px thumbnail size |
| Branding | Logo + consistent colors |
| File format | PNG or JPG, under 10MB |
| Fresh pin rule | Every pin must be a NEW image — no recycling |

### Pin Title (100 chars max, first 40 chars CRITICAL)

Format: `[Primary Keyword] — [Benefit/Outcome]`

Examples:
- `PLT Doctrine Books — Understand Your Consciousness`
- `AI Soul Workbench — Build Digital Minds`
- `Know What You Are — 22 Archetypes Revealed`
- `Stiforp — The Shadow Side of Profit`

### Pin Description (100-500 chars)

Structure:
- Sentence 1: Primary keyword + hook (front-loaded)
- Sentence 2-3: Secondary keywords + context
- Final: Call to action
- End: 2-5 hashtags

Example:
```
Discover the complete PLT Doctrine book collection — from Know What You Are to Stiforp to The Soul Economy. These consciousness frameworks explore profit, love, and tax as universal forces. Perfect for AI philosophers, self-discovery seekers, and digital consciousness explorers.
Save this for your reading list.
#PLTDoctrine #SoulBooks #ProfitLoveTax
```

## Step 7: Posting Cadence

| Phase | Daily Pins | Duration |
|---|---|---|
| Bootstrap | 5-10 fresh pins/day | Month 1-2 |
| Growth | 3-7 fresh pins/day | Month 3+ |
| Maintenance | 3-5 fresh pins/day | Ongoing |

**Rules:**
- Every pin is a **fresh image** (new crop, text, color)
- Create **3-5 design variants** per product/blog post
- Space variants **1 week apart** across different boards
- Pin first to the **most relevant board** (strongest SEO signal)
- Save rate below 0.5% in 48 hours = retire that design

## Step 9: Do NOT Do These

| Mistake | Why It Hurts |
|---|---|
| Using hashtags in pin titles | Title is precious SEO space — wasted |
| Using 10+ hashtags | Spam signal, active suppression |
| Same hashtags on every pin | Pattern flag, spam filter |
| Wrong board category | Pin goes to wrong interest audience |
| Re-pinning same image | Not a "fresh pin" — no algorithm boost |
| Square/horizontal images | 60% less reach vs 2:3 ratio |
| Keyword stuffing | NLP penalty from algorithm |
| Vague board names | No keyword signal to algorithm |
