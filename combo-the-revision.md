## The Three Moves

### 1. EYE — See the Flaw (Diagnosis)
*Load these guns:*
- `god-mode-research` — Full engineering protocol
- `soulguns-testing` — 65 tests, defect detection
- `diagnosis-soul-notes` — What's broken and why
- `game-mechanics-design` — The Consequence Test

*Action:* Read the codebase. Read the vision docs. Find the gap between them. Write the diagnosis.

### 2. GOVERNOR — Contain the Scope (Planning)
*Load these guns:*
- `pipeline-orchestration` — DAG-based task breakdown
- `context-window-control` — Memory budget, focus
- `game-loop-design` — Core loop first, secondary later
- `ecs-entity-system` — Separate data from logic

*Action:* Define exactly ONE thing to fix. Not 5. Not 10. One. Write the plan.

### 3. HAMMER — Break and Rebuild (Execution)
*Load these guns:*
- `input-feedback-systems` — Every action needs a reaction
- `game-ui-buttons` — Idle/hover/pressed/disabled states
- `construction-fx` — Buildings grow from ground
- `thought-bubbles-3d` — NPC thoughts visible

*Action:* Build the fix. Test it. Commit. Report.

---

## When to Use
When the city has drifted from the vision. When mechanics don't create consequences. When feedback is missing.

## Do NOT Use
When you're happy with the state. When the task is pure research.
